🧠 About This Project

This project demonstrates Artificial Intelligence using the Minimax algorithm. You play as X, and the computer plays as O. The AI evaluates possible moves to choose its best move.

⚙️ How It Works

  • 01. You select a cell on the board.
  • 02. The AI explores possible future moves.
  • 03. Minimax evaluates winning, losing and draw outcomes.
  • 04. The AI chooses a move with the best score.

📊 AI Scoring

+1 = AI wins
-1 = Player wins
0 = Draw
